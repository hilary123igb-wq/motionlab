Tournament

Every British Parliamentary debate distributes exactly six team points across four positions, so a perfectly balanced position averages 1.50. Deviations are measured here within each room, then averaged across the rooms that debated a given motion.

Because the comparison happens inside a single room, differences in bracket strength largely cancel. What remains mixes genuine motion asymmetry with residual skill differences between the four teams drawn together — the latter is not yet controlled for.

How this is built

Pipeline
Tabbycat public API └─ raw JSON, stored immutably, one file per response └─ DuckDB warehouse (rounds · motions · teams · debate_teams) └─ SQL mart (per-motion position statistics) └─ JSON export └─ this page

Where the numbers come from

Tournament results are read from the public Tabbycat REST API by walking its own links: tournament → rounds → pairings → ballots. Results are not included in the draw, so every debate needs its own ballot request — roughly 830 requests for one tournament. Each response is written to disk unchanged with its source URL and fetch timestamp, and never re-fetched.

How the effect is computed

For each debate, gov_opp = (OG + CG)/2 − (OO + CO)/2. That value is averaged across every room that ran a given motion, and the standard error comes from the spread of those per-room values. Computing per room first is what makes an honest confidence interval possible — and it means bracket strength largely cancels, since the four teams in a room have similar records.

Scope and known limits

Preliminary rounds only. Elimination rounds use a pre-filtered field and different draw rules, so including them would distort the averages. Effects are not adjusted for team strength, position-balance constraints in the draw, or judging panel quality. With nine motions from one tournament, differences between motions are far less certain than the estimate for any single one.

Privacy

Speaker names and individual speech scores are removed at the ingestion boundary, before anything is written to disk. MotionLab stores team, position, and result only.
